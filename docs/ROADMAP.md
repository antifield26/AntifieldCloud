# 里程碑规划（ROADMAP）

> 本文件只写**里程碑目标、顺序、总量与风险**。任务明细（编号/状态/依赖/工作量/验收）一律以 `docs/TASK-INDEX.md` 为唯一事实源，此处不重复列表。

## 主线

个人工作台 + 树莓派控制台：公网安全可用 → 每天愿意打开 → 控制台能判断处置 → 按需自动化。

```text
P0 地基(完) → P1 效率/自动化/门户(完) → P2 收尾(完)
    → P3 安全收口(现在) → P4 通用工作台 ∥ P5 树莓派控制台 → P6 自动化(可选)
```

## 里程碑一览

| 里程碑 | 目标（出口叙事） | 状态 | 总量 | 主要风险 |
|---|---|---|---|---|
| **P0 地基** | 公网登录 → AI 真实任务 → 控制台可见 → 白名单外被拒 → 备份+演练 | done（日历 streak 见 P3 `P0-STREAK`） | ~15h | R1 Java 内存；R2 SD 写入；R3 备份目标 |
| **P1 效率+自动化+门户** | CRUD/流水线/watchdog/SPA 五页可用 | done | ~12h | 依赖漂移；配置漏发 |
| **P2 收尾** | 指标导出、审计硬化；插件化/多目标备份 drop | done（P2-01/03 dropped） | ~4h | — |
| **P3 安全收口+可运维** | 评估缺口实机闭合：强口令、认证覆盖、可追溯、streak、演练 | **进行中** | ~5–6h | 换密旧会话；streak 依赖定时器 |
| **P4 通用工作台** | AI 真流式 + 效率好用 + 可搜可导出 + 手机能用 | pending | ~12–13h | SSE 与适配器边界；Markdown XSS |
| **P5 树莓派控制台** | 曲线/SD 代理/日志排障/告警外送 | pending | ~9–10h | SD 只能代理指标；外送通道配置 |
| **P6 自动化与门户** | 模板化重复运维；门户反代卡片 | 暂缓（用满两周再开） | ~6–8h | 反代变开放代理（必须锁 localhost） |

## 顺序与启用条件

1. **先 P3 后 P4/P5**：安全收口未实机闭合前，不扩公网能力面。
2. **P4 与 P5 可并行**（不同会话）；共享 `/api/*` 或 `wb.db` schema 时先合主线。
3. **P6 默认不排期**：P4/P5 使用 ≥2 周且痛点命中 TASK-INDEX 中 P6 条目再逐项开。
4. 任一新任务：先在 TASK-INDEX 建行（依赖/工作量/验收），再动手。

## 里程碑级风险（持续）

| ID | 风险 | 等级 | 应对 |
|---|---|---|---|
| R1 | minecraft 常驻 ~2.4G，挤占 AI/网关 | 高 | MemoryMax + 告警；P5-04 可见占用；启停另议 |
| R2 | SD 单盘、无寿命读数 | 高 | 写入减负 + 每晚备份 + P3 演练自动化 + P5-02 代理指标 |
| R3 | 备份含密钥面 | 中 | 已脱敏 env；强口令；PC 目录权限收紧 |
| R4 | 登录会话 ≈ workbench 权限 | 中 | P3-02 敏感操作确认；禁止多用户前不扩写权限面 |
| R5 | cloudflared 边缘抖动 | 中 | watchdog + 白名单 restart |

详细技术对策与实测数据见 `docs/RESEARCH.md` §8、`docs/ARCHITECTURE.md` §5。

## 跨里程碑原则

- 一次会话一个任务 + 实机验收（“本地跑通”不算）。
- 完成即更新 TASK-INDEX；接口/schema/安全变更同步 ARCHITECTURE；事故进 CHANGELOG。
- 红线见 `AGENTS.md`：零入站、serve 只绑 localhost、密钥不进库、动存储前备份 `status=ok`。
