# Roadmap

## v0.1.0（当前 MVP）

- 动态上下线、稳定重连、AI 聊天、按玩家记忆、状态/移动指令、本机 HTTP。
- 验收：`docs/ACCEPTANCE.md`。

## v0.2 自动化玩法

- 钓鱼、种田、采集（带库存/安全边界）、战斗/逃跑、睡觉跳夜（Vote2Sleep）。
- 更稳的 `come/follow`：跨维度/实体未加载时通过 RCON 读取位置（只读）。
- 运动安全：坠落/岩浆/水域策略、卡住检测、自动回家。

## v0.2 管理助手（只读）

- 经 RCON 查询 TPS、白名单、备份状态。
- 不做踢人/封禁/备份触发等写操作；写操作仍由 AntifieldCloud 管理。

## v0.3 对接增强

- AntifieldCloud 面板展示 Lofii 状态/聊天记录（用户主导）。
- 事件推送：SSE 或 webhook，供面板实时显示游戏内聊天。
- 可选 HTTP 控制接口（严格 Token + 指令白名单 + 审计）。

## v0.3 可靠性与安全

- 命令审计、Token 轮换、指标历史、告警。
- 离线模式名称冒用的缓解（HTTP-only 管理指令或共享口令）。

## v0.4 体验

- 多角色人设、记忆摘要、主动问候（可开关）、皮肤、语音。
- 聊天与 Discord/QQ 互通（复用 AntifieldCloud Bot 能力，用户主导）。
